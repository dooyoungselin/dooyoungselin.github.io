# Dooyoung & Selin

블루 드로잉 모바일 청첩장의 현재 디자인 버전입니다.

- 사이트: https://dooyoungselin.com/
- 예식: 2027년 2월 13일 토요일 13:30, 대전 씨엘드레브 르자르뎅홀
- 호스팅: GitHub Pages, `main` 브랜치의 저장소 루트
- 도메인 및 DNS: Spaceship

## 현재 기능

- 휴대폰 화면에 맞춘 넓은 표지, 손그림에서 원본 사진 오리기로 이어지는 자동 전환과 실제 전환마다 반복되는 작은 파란 스프링클, 그림/사진을 클릭하거나 탭해 양방향 전환
- 사용자가 제공한 PNG 테두리, 상반신 손그림과 아치형 이름을 담은 카카오톡 공유 전용 썸네일
- 표지 제목·이름·날짜·장소는 제공된 손글씨 PNG를 원본 비율로 표시하고, 그 밖의 영문은 Delius, 한글은 고운돋움을 사용
- 주소창과 안전 영역을 고려한 첫 화면, 내용 높이에 맞춘 아래 섹션과 부드러운 스크롤, 흰색 배경
- 사진 전체를 원본 비율로 보여주는 10개 앨범 장면(각 3장), 크기와 위치를 달리한 배치
- 확대 화면에 항상 보이는 이전/다음·닫기 및 키보드 조작
- 약도와 카카오·네이버 지도 버튼을 묶은 화면, 별도 교통 안내 화면의 주소 복사·셔틀 시간·펼쳐 보는 대중교통과 주차 정보
- RSVP와 방명록 입력 **미리보기**: 전송하거나 저장하지 않음
- 음악 버튼은 실제 재생·음소거 상태를 반영하며 자동 재생하지 않음. 승인된 음원이 연결되기 전에는 비활성 표시를 유지하고, 누르면 음악 준비 중 안내만 표시

Google Sheets 응답 저장과 방명록 공개/관리, 승인된 음악 파일 연결은 추후 구현합니다. 현재 검색 제외(`noindex,nofollow`)를 유지합니다. 검색 제외는 접근 제한이 아니며 사이트와 저장소는 공개입니다.

## Codex 작업 설정

프로젝트 전용 `.codex/config.toml`에서 Astra가 기획·관리·검토를 맡고, Luna는 범위가 정해진 구현을, Sol은 복잡한 여러 파일의 디버깅·통합을 맡습니다. 프로젝트 설정은 사용자의 샌드박스 권한을 상속하며, 과거 메모리 자동 참조 지침과 새 메모리 생성을 이 프로젝트에서만 끕니다. ponytail과 markitdown-local을 사용하고, 공식 [`openai/skills`](https://github.com/openai/skills) 저장소에서 설치한 Playwright skill도 있습니다. npm·플러그인 캐시는 문맥으로 불러오지 않으며 삭제하지 않습니다. 설정은 다음 세션부터 적용되며, 현재 세션에서는 작업을 명시적으로 위임합니다.

## 개발

패키지 설치나 빌드 없이 `python3 -m http.server 8765 --bind 127.0.0.1`로 확인합니다.

- `index.html`, `style.css`, `app.js`: 화면과 동작
- `venue-map-v3.png` (1086×1448): 위치와 참고용 도보 거리·시간, 셔틀 왕복 시간을 표시한 손그림 약도이며 원본 비율 그대로 표시합니다.
- `index.html`의 숨겨진 `#background-music`: 음원 미연결 상태로 제공됩니다. 승인된 파일이 준비되면 해당 오디오 요소에 `src`를 지정하거나 `<source src="…">`를 추가하세요. 자동 재생은 하지 않습니다.
- `gallery-manifest.json`, `assets/gallery/`: 최적화 사진과 썸네일
- `assets/couple-user-cutout-v2.png`: 사용자가 제공한 투명 인물 사진을 원본 비율로 웹용 축소한 파일. 원본 사진은 수정하지 않으며, 드레스의 시각적 무게를 보정하도록 인물 무대를 오른쪽으로 8% 이동하고 스프링클은 히어로 중앙에 배치
- `invitation-frame-v1.png`: 사용자가 제공한 원본 테두리 PNG
- `assets/cover-*-v1.png`: 제공된 손글씨 이미지에서 제목·이름·날짜·장소를 각각 잘라낸 투명 PNG. 원본 획과 색을 유지하며 읽기용 텍스트를 함께 제공
- `share-kakao-v1.png`: 승인된 카카오톡 공유용 1774×887 PNG
- `AGENTS.md`, `DESIGN.md`: 구현·디자인 규칙
- `CNAME`, `.nojekyll`: 기존 Pages 도메인/정적 배포 설정
- `?review=1`: 글꼴 및 그림/사진 정렬 검토 화면

원본 고해상도 사진, 생성형 편집으로 만들었다가 제외한 이미지, 개인 응답과 인증 정보는 배포하지 않습니다. `artifacts/`는 로컬 작업 기록으로 Git에서 제외합니다.

## 배포

`main`에 변경 사항을 올리면 GitHub Pages가 배포합니다. 배포 후 실제 도메인에서 표지 전환과 갤러리를 확인합니다. RSVP·방명록을 연결하기 전에는 저장 성공 표시를 만들지 않습니다.

DNS는 apex에 GitHub Pages A 레코드 4개(`185.199.108.153`~`185.199.111.153`), `www`에 `dooyoungselin.github.io` CNAME을 사용합니다. GitHub 도메인 소유권 확인 TXT를 유지하고 HTTPS를 사용합니다.
