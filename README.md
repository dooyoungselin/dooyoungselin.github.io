# 모바일 초대장

정적 파일로 제공하는 모바일 초대장 프로젝트입니다.

## 개발

패키지 설치나 빌드 없이 로컬에서 미리 볼 수 있습니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

## 주요 파일

- `index.html`: 페이지 구조와 콘텐츠
- `style.css`: 화면 스타일과 반응형 레이아웃
- `app.js`: 화면 상호작용

## 기능 상태

RSVP와 방명록은 화면 미리보기이며, 응답을 전송하거나 저장하지 않습니다.

## 배포

GitHub Pages에서 저장소 루트의 `main` 브랜치를 배포 대상으로 사용할 수 있습니다.

## 개인정보

공개 저장소와 공개 사이트의 콘텐츠는 누구나 읽을 수 있습니다. 개인 응답, 인증 정보, 비밀값은 커밋하지 마세요.
